# Alansari.Tech Plugins

## Claude.ai (web / phone browser)
Customize > Plugins > Add > Add marketplace > Add from a repository > `alansari-plugins`, then install **alansari-motion** and turn on Sync automatically.

## Claude Code
```
/plugin marketplace add alansariteach/alansari-plugins
/plugin install alansari-motion --marketplace alansariteach/alansari-plugins
```

Plugin: **alansari-motion** — 1000 motion presets + 123 fonts, applied by ID.
